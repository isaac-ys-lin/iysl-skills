# 既有檔案的套用

新簡報用 `build-deck.js` 產生，不需要本文件。本文件用在改既有的 PowerPoint、Word、Excel 或 HTML；
只讀本次涉及的格式，沿用環境中已有的格式工具。

## 數據從哪裡來

在副本上改，保留原檔。數據取自原生圖表的內嵌工作簿、可存取的來源檔、同頁表格或 HTML 結構化資料；
兩處數字不一致時指出來。只有點陣圖、沒有可靠數據時保留原圖，列出重畫需要的資料。
重畫後，圖說與正文引用的數字跟著新圖一致。

## PowerPoint

- 保留文字方塊、表格、備忘稿與頁序；只替換目標圖表。
- 能用原生圖表的圖型（見[圖表輸入](chart-inputs.md)）優先改原生圖表的顏色與字型，保留「編輯資料」。
- 嵌入 SVG 時，`a:blip` 指向同尺寸 PNG 後備，`asvg:svgBlip` 指向 SVG（Office 2019／365 顯示 SVG，
  舊版與 LibreOffice 顯示 PNG）。PNG 用 `node "$SKILL_DIR/scripts/svg-to-png.js" chart.svg chart.png` 產生。
- 圖片框與 SVG `viewBox` 同比例，不拉伸；替代文字寫圖表標題與一句重點。

## Word

- 保留段落、標題、表格、頁首頁尾、圖說與交叉引用；只替換原圖片節點。
- 圖寬受版心限制，用 `layout: "document"` 與實際寬度產生 SVG；圖下保留可編輯的資料表或圖說。
- 嵌入方式與替代文字同 PowerPoint。

## Excel

- 保留儲存格值、公式、型別與工作表。需要隨資料更新時用原生圖表並套全球藍色彩；
  SVG 只是資料快照，交付時說明它不會隨儲存格更新。

## HTML 與 SVG

- 保留語意文字、表格、錨點與導覽，把新 SVG 放回原圖容器。獨立 SVG 本身要帶單位、期間與來源。
- 在瀏覽器看預期寬度與窄螢幕；密集圖表在窄螢幕可在容器內橫向捲動，頁面本身不橫向溢出。

## 交付

改的是使用者自己的檔案，所以交付時說清楚動了什麼、沒動什麼：哪些圖重畫了、數據取自哪裡、
哪些因為缺資料保留原樣。成品看過哪些頁、用什麼看的（例如 LibreOffice 替代字型）也照實寫。
