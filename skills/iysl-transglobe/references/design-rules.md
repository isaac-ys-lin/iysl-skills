# 全球藍設計規則

此參考用於把內容套用為全球藍風格。它是來源支持的應用規範，
不是完整或已核准的企業 CIS。

版本差異詳見[來源研究](https://github.com/isaac-ys-lin/iysl-skills/blob/eaae0419c379def4d483747e0c26f6df028bc95a/reports/transglobe-sources-research.md)。

## 基本色彩角色

| 角色 | 色碼 | 用途 |
| --- | --- | --- |
| 閱讀主體 | `#111111` | 正文、數字、表頭、座標軸 |
| 次要文字 | `#4A4A4A` | 註解、說明、來源 |
| 封面標題 | `#000066` | 白底封面或結尾的主標 |
| 內頁標題 | `#000099` | 白底內容頁標題 |
| 資訊焦點 | `#28317B` | 標題點出的對象或主資訊 |
| 比較脈絡 | `#7F7F7F` | 焦點以外的比較項 |
| 深色章節底 | `#142979` | 章節／結尾頁，配白字 |
| 行動強調 | `#AD540B` | 每頁最多一個非圖表序列的行動重點 |
| 風險／警示／良好 | `#9D2324` / `#9D5F00` / `#015224` | 狀態的輔助色 |

白底是分析圖表、表格與內容頁的預設。不要把網站的深色 UI 表面誤用成
深藍圖表底色。狀態必須同時有符號與文字，不能只靠色彩；可用 `▲`、`●`、
`■` 與清楚標籤。灰色停用狀態用 `#B3B3B3`，仍保留文字。
數值正負不自動代表風險／良好；只有來源或任務定義了狀態時才套狀態色。
一般比較仍用 Focus 的藍／灰，以正負號、零基準與直接標值表達方向。

## 圖表先選閱讀模式

先確認讀者要查精確數字、比較差異，還是追蹤類別；色彩要支援答案，不是裝飾。

### Focus：預設的單一焦點比較

適用於標題明確指出一個比較主角。該對象用 `#28317B`，其他可比項用 `#7F7F7F`。
同期排行／跨類別比較選一個資料支持的主角，並讓標題點出它；共用同一指標
不代表所有類別都是焦點。同一被選中的序列跨時間可有多個藍色標記，
比較序列仍用灰色。

### Ordered：有方向或大小順序

適用於連續或有意義的大小階層。保持資料原有順序與分級，使用下列由淺至深的
連續藍階，通常從 `seq2` 開始；不要為配色而新增或刪除級距。

| 色階 | 色碼 |
| --- | --- |
| seq1 | `#D1DDF7` |
| seq2 | `#9DB1D9` |
| seq3 | `#7285BB` |
| seq4 | `#4B5A9C` |
| seq5 | `#28317B` |

### Categorical：固定、無序、需要跨標記追蹤的類別

只有固定無序類別在多個標記或時間點需持續辨識時才使用。淺底色盤依序為
`#28317B`、`#04696C`、`#4A8F5B`、`#D09FE2`，最多四類加既有的「其他」
（`#DDDDDD`）。螢幕用純色並直接標註每類，折線加線型或標記；網點僅供黑白列印。
類別超過容量時，
改用小倍圖、表格或拆圖；未經授權不得自行合併為「其他」或刪除類別。

Categorical 圖不再加 Focus 強調或行動橘色；其中首色藍代表類別身份。
合計優先用位置、粗體與
分隔線表達，無須再加深色底。密集 KPI 的數字放白底或中性底，細條只輔助比較；
維持原比例尺、基準線與超額標記。

## 字型與層級

| 角色 | Windows 優先 | macOS 後備 | 使用位置 |
| --- | --- | --- | --- |
| 文字／資料 | Arial + Microsoft JhengHei | PingFang TC | 正文、圖表、表格、KPI |
| 展示 | Cambria + PMingLiU | Songti TC | 封面、章節、文件報告標題 |

標題使用粗體，正文使用一般字重。數字與資料表保持文字／資料字型。只使用可用的
本機字型；若發生替代，檢查中文、數字、換行與截字，而非假設版面不變。

## 容器與尺度

完整簡報才使用 16:9 的 1280 × 720 基準：左右與上方 64 px、下方 56 px。
封面 64 px、章節 52 px、一般標題 36 px、正文與副標 24 px、標籤 20 px、
圖說 18 px、來源 16 px；KPI 可用 120 px，次級指標 52 px。
投影用正文至少 24 px、資料／表格 20 px、軸標 18 px、來源／頁碼 16 px。
PowerPoint 960 × 540 對應為 px × 0.75 的 pt 值。白底封面用 `#000066`，
章節與結尾用 `#142979` 配白字。
全頁簡報中，含圖頁帶來源，非封面帶頁碼，圖表／表格頁帶 exhibit 編號；
保留既有編號的引用關係。這些結構規則不要求把文件或純圖補成完整簡報。

純 SVG／圖表保留原始比例，依最終閱讀尺寸決定字級與留白，不機械套用投影片的
16:9、邊距或最小字級。文件與 HTML 長報告維持連續閱讀、段落與表格結構；
可以採展示字型做報告標題，但不要把每頁改成投影片。內容放不下時，重排、拆頁或
拆圖，不靠縮小文字硬塞。

## 圖表與表格細節

閱讀重量來自面積、對比、粗線與重複次數，不只色碼。先減少不必要填色、調整
留白與字重，再考慮新增色相。淺灰區塊可用於分組，外圍保持白底；背景框必須包住
標題和資料區，不能碰撞圖例、標記或文字。

表格用深色文字和細中性線。焦點列可用 `#28317B` 的極淺底或藍色粗體名稱；
不要以整片深藍底取代可讀數字。保留指標定義與資料標籤；調整排序或比例尺
須維持原意，長條不可截斷零基準而誇大差距。文字對比以 4.5:1、必要圖形
以 3:1 檢查；淺色填色可用清楚輪廓與深色標籤補足辨識。

## 已知限制

Office `.thmx`／`.potx` 只可作可選起點，並非 HTML 簡報的轉檔權威。舊版
`CHART-READABILITY.md` 的 `#27327B` 等範例色碼已被本規則中已核對的角色取代。
原型只校準過 Focus；Ordered、Categorical 與跨平台 Office／列印仍需按實際成品
檢查。
skill 擴充圖型（`grouped`、`combo`、`histogram`、`sharetrend`）沿用本規則的色彩角色與字級，
但不在網站 v2.5.1，也未經原型或 Office 實機校準。
