# Optional style exploration

Use this reference only when the user asks to compare directions, when brand or
audience preference cannot be inferred, or when the first direction has a
demonstrated quality gap. It is not a required preamble for outline work.

When exploring, propose a small set of genuinely different directions. A useful
set can include the topic's natural direction, a reasoned inversion, and a
content-specific wildcard. Compare brightness, color strategy, type mood,
image language, density, and spatial staging; palette-only changes are not
meaningful alternatives.

Once a direction is chosen, normalize it into one `STYLE_INSTRUCTIONS` block.
For an existing anchor, inherit visual language only—palette proportions,
line weight, whitespace, icon and label treatment—not the anchor's content or
composition. If the user asks to proceed directly, select one direction and
record the rationale only in the handoff, not as a forced outline section.
