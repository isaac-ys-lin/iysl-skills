# 格式與驗收

只讀取本次涉及的格式。既有格式 skill 或工具可用時沿用；本文件不指定
函式庫，也不把「套件成功儲存」視為渲染成功。

## 原數據重繪與替換

修改既有文件時，先建立可核對的「原圖所在位置 → 來源數據 → 新圖」對應。
保留未修改的輸入檔；依報告問題重選圖型，使用同一份數據重繪並放回文件副本。
從原生圖表的內嵌資料、可存取的來源工作簿、同頁表格或 HTML 結構化資料取值；
圖表快取與工作簿不一致時指出衝突，先完成不受影響部分。只有圖片且無可靠數據時，
保留該圖並指出缺口，不從像素猜值。

JSON 保留全部原始觀察值、單位、期間、來源位置與缺值；排序、百分比、差值、
累計與指數可從同一份數據計算，並記下分母／基期。原值與衍生值分開，
更新圖說與結論時同步核對，避免圖換了而段落仍引用舊口徑。
完成標準是修改後文件中的圖表、上下文與數據一起通過核對，另外附可重製檔案。

使用內附 renderer 時，依[圖表輸入](chart-inputs.md#文件尺寸與資訊層級)選擇 document／slide
layout，先量容器的可用英吋寬度。依實際置入尺寸換算字級並核對等比例圖高；
改版或拆頁優先於縮圖。字級換算只驗證尺寸，仍需查看原生文件中的換行及裁切。

## PowerPoint／PPTX

- 優先讀取圖表系列與內嵌工作簿（或可存取的連結來源）；同頁表格也可作為明確來源。
  記錄投影片／物件對應，替換目標圖表，保留其他文字、圖說、備忘稿、表格與頁序。
- 保留文字方塊、表格、頁碼等原生物件，圖表優先嵌入 SVG 並附來源檔。
- 圖片框與 SVG viewBox 維持相同比例；需要留白時用等比例縮放，不拉伸。
- 依實際投影片尺寸換算設計規範的 px，勿直接當成 Office pt。
- 驗證文字與數據保真、圖片關聯與媒體完整、投影片比例；查看改動頁的
  標題層級、標籤／來源字級、裁切與閱讀順序。

## Word／DOCX

- 從原生圖表或來源表格擷取數據，保留圖說／交叉引用與所在段落位置。
  替換圖形後仍保留可編輯的數據表及圖說，並核對正文引用的數值。
- 使用段落、標題、表格、頁首頁尾的原生樣式；依文件頁寬與閱讀距離排版。
  報告主標可用展示字型，內文與資料用閱讀字型；不照搬簡報字級。
- 圖表 SVG 保持比例，尺寸受可用頁寬限制；圖說、單位與來源保持文字可編輯。
- 替換圖片時限定原圖片節點／關聯，保留前後段落及表格。比對原生文字與
  表格清單，特別檢查分頁後的標題、空白頁、表頭對比及內容是否消失。

## Excel／XLSX

- 保留儲存格值、公式、資料型別與工作表；圖表可放在獨立呈現區，原資料仍可編輯。
- SVG 是資料快照。交付生成來源並說明如何重製；編輯儲存格不會自動重繪它。
- 驗證值及公式與原檔一致、圖片關聯有效、圖框等比例；實際查看字型、
  標籤與圖表有無遮住儲存格，期間／單位／來源是否可見。
- 若需求是隨資料變動自動更新，使用可支援的原生圖表並明示其樣式差異。

## HTML／SVG

- 從頁面中的資料表、圖表 spec 或明確資料來源擷取數據，保留語意內容、錨點及導覽；
  將新 SVG 替換到原圖所在容器，必要時調整容器與圖說。
- HTML 保留語意文字與表格；SVG 提供 viewBox、可辨識的標題／說明及直接標籤。
  真正向量圖以文字、路徑與圖形組成；點陣素材保留自身格式及來源說明。
- 獨立交付的 SVG 本身保留期間、單位、來源及影響解讀的註記，
  不只放在外層 HTML；脫離報告後仍能正確解讀。
- 文字／文件版面可隨視窗換行。固定比例簡報與密集圖表在窄螢幕提供放大或
  容器內橫向捲動，避免把標籤縮到難以閱讀；頁面本身不應意外橫向溢出。
- 確認 HTML／SVG 可解析、資料與生成來源對應，並在實際瀏覽器查看預期尺寸；
  若用於網頁，也查看窄螢幕的換行、標籤、裁切與圖表捲動。

## 驗收證據

分開記錄三種結果，依改動範圍選最小有效檢查：

1. **內容保真**：數值、正負號、零／缺值、單位、期間、來源、公式及語意
   都能對回原檔。重排後的文字／表格仍完整；新標題沒有加上未支持的因果或趨勢。
2. **文件結構**：用格式工具讀回輸出。對 Office 檢查內容、圖片及關聯，
   對 HTML／SVG 檢查解析與資源；以交付的資料和生成來源重製 SVG。
3. **實際渲染**：查看改動部分，核對圖框比例、字型角色、密度、對比、標籤
   與來源。使用替代渲染器時記錄其名稱，不能當成目標 Office 程式已驗證。

無法開啟目標程式時，仍可交付已完成的副本及結構檢查，明示渲染待驗。
PDF／列印與跨平台相容只在實際測過時宣稱；需要 PNG 相容預覽時可附帶，
依最終置入尺寸輸出足夠解析度（文件約 300 dpi，簡報至少覆蓋預期投影像素），
保留 SVG 主檔並說明該預覽的可編輯性。
