# 選圖指南

先寫出這頁標題要說的那句話，再挑讓讀者一眼看到它的圖。使用者指定圖型就照做；
沒指定就直接選，交付時用一句話說明理由。

- **要不要圖。** 只有一個數字用 `kpi` 版型；讀者要逐項查精確值、或項目很多時用 `table`；
  沒有數字的並列、流程與選項用 `columns`、`process`、`compare`。
- **問題決定圖。** 同一份資料，問「誰的總量大」用 `ranking`，問「各自的組成」用 `stacked`，
  兩者都要看用 `mekko`。兩個時點看差距用 `dumbbell`，三期以上看走勢用 `trend`。
- **有些圖本身就是一句主張。** 漏斗說「同一批對象逐段流失」、瀑布說「各項可加總」、
  帕累托說「原因互斥」、箱型與直方圖說「這是真實分布」、龍捲風說「有一個算好的模型」、
  矩陣說「兩個評分有定義」、指數化說「起點可比」。資料有這個結構時它們最有力；
  沒有時改用排行或表格，並說明還缺什麼資料。
- **類別多於四個**（調色盤只有四色加「其他」）時，拆圖、用小倍圖或表格，保留每個類別。
- **一頁一張圖。** 兩組資料要對照時拆頁，或用 `grouped`、`combo`。
- **上色**跟著閱讀模式：標題點名主角時填 `focus`，其餘自動轉灰；細節見[設計規範](design-rules.md)。

## 圖型

| `chart_id` 圖型 | 最適合回答的問題 |
| --- | --- |
| `ranking` 排行比較 | 同期誰高誰低、焦點在哪 |
| `ordered` 階段與強度 | 有順序的等級或區間分布 |
| `trend` 單一趨勢與同業 | 主角與比較對象隨時間如何變化 |
| `tracking` 跨期追蹤 | 2–4 個固定類別在各期如何變動 |
| `grouped` 多序列分組長條圖 | 各項目在 2–4 個序列（年度、情境）下的大小 |
| `stacked` 100% 堆疊長條圖 | 各群的內部組成有何差異 |
| `sharetrend` 組成隨期間變化 | 固定類別的占比如何隨期間移動 |
| `combo` 金額柱＋比率線 | 規模與其比率（年增率、達成率）如何一起變化 |
| `bullet` 實際與目標 | 實際離既定目標多少 |
| `waterfall` 瀑布圖 | 期初加減後如何到期末 |
| `dumbbell` 啞鈴圖 | 每個相同項目前後差多少 |
| `heatmap` 二維強度 | 兩個維度交叉後哪裡高低 |
| `funnel` 漏斗圖 | 同一批對象在哪階段流失 |
| `waffle` 百格占比圖 | 單一整體由哪些互斥部分構成 |
| `mekko` Marimekko 市場結構圖 | 群體總規模與內部組成如何同時不同 |
| `pareto` 帕累托圖 | 少數互斥原因是否占主要件數 |
| `indexed` 指數化小倍數趨勢圖 | 不同起始規模的相對成長誰較快 |
| `tornado` 敏感度龍捲風圖 | 哪個假設範圍令模型結果最敏感 |
| `scatter` 散點圖 | 兩個量是否一起變動、有哪些例外 |
| `box` 箱型圖 | 各群典型值、離散程度與離群值 |
| `histogram` 直方圖 | 逐筆觀察值集中在哪、分布是否偏斜 |
| `matrix` 2×2 優先矩陣 | 哪些方案在兩個已定義評分維度上值得優先 |

`grouped`、`combo`、`histogram`、`sharetrend` 是 skill 擴充，原型網站沒有，沿用同一套色彩與字級。
