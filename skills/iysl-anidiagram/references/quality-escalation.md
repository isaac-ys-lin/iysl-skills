# Optional quality escalation

Use these tactics only when the first candidate cannot satisfy the visual or
delivery contract, or when the user explicitly requests alternatives.

## Multiple candidates

Keep the semantic relation and must-keep facts fixed. Give each candidate a
different composition or spatial staging as well as a meaningful visual
difference; palette-only changes are not sufficient. Record a short visual and
spatial fingerprint so the choice is inspectable.

## Blind review

For a high-value delivery, let an independent reviewer inspect source, poster,
and sampled frames without seeing the author's rationale first. Ask for only
actionable findings: coverage, relation-to-motion fit, hierarchy, contrast,
collisions, loop seam, and poster completeness.

## Sampling and revision

Sample roughly 3–6 frames according to duration and complexity. Add a revision
round only for a concrete validator or visual finding. Re-run
`render_svg.py --check` after each revision and stop when the acceptance floor
is met; do not create review paperwork for every element.
